# Code style

No code exists in this repo. These rules apply to docs and git.

- Use Simplified Technical English. Active voice, short sentences.
- No em dashes. Dates as DD/MM/YYYY.
- Write paths as `~`, not `/Users/<name>`.
- Commit subject: imperative, under 72 characters, format `type: summary`. No AI co-author line. Never force-push.
