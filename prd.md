# Product requirements

## Goal

Record the state of Forza Horizon 4 (Steam) on an M-series Mac through CrossOver 26.3 and Apple D3DMetal. Record how it shares CrossOver with Forza Horizon 5 on the same Mac.

## Users

Mac players with a Steam copy of FH4 and CrossOver. Test machine: M4 Pro, 24 GB RAM.

## Output now

- research.md with proven facts and unknowns.
- A test list for Adam (testing.md).

## Not in this repo

- Patches, proxy code or binaries. Use the third-party project (README.md).
- An install guide. Nobody here tested the third-party install.

## Out of scope

- Cracks, DRM removal, license bypass.
- Steam emulators, fake AppIDs, ticket emulation.
- DLC unlock lists, achievement emulation.
- Any edit to the game EXE on disk.

If a finding depends on an out-of-scope item, write "blocked by scope" and stop that line of work.

## Success check

research.md has no "unknown" for the FH4 launch result, with a log or a screenshot as proof.
